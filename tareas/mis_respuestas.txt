PREGUNTA 1 (5 pts)
¿Cuál es la diferencia entre "git add" y "git commit"?

Tu respuesta:
[el git add es para agregar algo a alguna carpeta y el git commit es para guardar cualquier cambio que se haga]

----------------------------------------------------------------
PREGUNTA 2 (5 pts)
¿Qué hace el comando "git pull"? ¿Cuándo debes usarlo?

Tu respuesta:
[Para actualizar el repositorio y se utiliza más que nada cuando uno deja de trabajar y vuelve para ir trabajando lo mas actualizado posible]

----------------------------------------------------------------
PREGUNTA 3 (5 pts)
¿Qué diferencia hay entre un repositorio local y uno remoto?

Tu respuesta:
[El repositorio local es el que esta en el computador y el remoto en el servidor llamado nube]

----------------------------------------------------------------
PREGUNTA 4 (5 pts)
Escribe la secuencia completa de comandos para subir un nuevo
archivo llamado "datos.csv" a GitHub (desde git add hasta push):

Tu respuesta:
[Para subir un archivo "datos.csv" a GitHub, la secuencia estándar comienza preparando el archivo para el seguimiento, 
registrando el cambio y enviándolo al servidor remoto. Utilizando git add "datos.csv" para añadir el archivo al área de preparación 
(staging area) luego, ejecuta git commit -m "Agregar archivo datos.csv" para crear una instantánea local del cambio con un mensaje descriptivo.
 Finalmente, usa el comando git push origin main. verificar "main" sea el nombre de tu rama  para cargar los datos a tu repositorio en la nube]
